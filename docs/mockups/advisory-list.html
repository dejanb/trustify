Design Notes:
  • Vulnerability Gallery - Shows total count + breakdown by CVSS severity using colored chips
  • Source Label - Indicates where the advisory came from (Red Hat, CVE, GitHub, etc.)
  • CSAF advisories (Red Hat, etc.) typically have multiple vulnerabilities
  • CVE/OSV advisories typically describe a single vulnerability
  • Severity chips are derived from CVSS scores of each vulnerability
